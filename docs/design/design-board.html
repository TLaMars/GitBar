Menu bar icon states (D15) — as shipped in v2.1.0

The icon stays a monochrome template image (the GitBar glyph, appearance-adaptive); a small colored dot next to the count carries the most urgent state, red > orange > green, no dot otherwise (get-menu-bar-tint.ts, PopoverAppDelegateSubscriber.swift). Open item 3 — per-event notification settings (D16.5)

Settings › App. The master toggle stays the gate; sub-toggles filter events before the urgency collapse. "My PR needs work" bundles changesRequested / ciFailed / conflicts behind one switch. Defaults: all on. Master off dims the group.

Open item 4 — snooze for 1 day, two candidate homes

The store already supports date-based snoozing; only until-updated is surfaced. Both options build on the shipped hover slot (Snooze · Hide text actions). Option A is the lazier build — one extra action, no new menu component; the right-click menu was dropped precisely because native menus need a new module.

Open item 2 — "commented" notification event

Open item 6 — banner retraction on the falling edge

No new UI — Notification Center just stops lying. When the signal behind a PR's last-sent banner goes false (the same falling edge that re-arms the latch), one native call removes the delivered notification by its accountId:id identifier.
